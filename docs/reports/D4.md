## House style in brief
- Kept as `src/shared/pdf.js` draws it: crest top left, bold "NIGERIAN NAVY — CIRERMS", muted system name, navy bold title, optional subtitle, navy rule, footer "RESTRICTED — Nigerian Navy CIRERMS | Generated by: <name> | <date time>" left and "Page X of Y" right on every page (Chromium footer template), the colours and the navy table header (since the owner's review: navy text, no fill, a 1.3 px navy line under it).
- Copied from NAVY-PAYROLL: crest watermark (opacity 0.02, fixed, centred, full page height), `@page` background `#f8fbff`, Inter for text, Libre Baskerville for titles and headings, Courier New for codes, figures and dates. Fonts are local files.
- Improved: label and value fact rows with hairlines; a summary strip; headings with a teal rule; tables with a repeating header row (navy text, navy line under, no fill), whole rows, stripe, right-aligned figures, group and totals rows; struck lines for "not recommended"; signature blocks with Date lines; portrait for forms, landscape for wide tables.

## Decisions taken where the brief was silent
- The header (crest, title) appears on page 1 only, as the app's PDFs do; the footer and the table header row repeat on every page.
- The "Generated by" date and time is written dd/mm/yyyy hh:mm UTC (the app's own rule for dates; today it prints ISO).
- Names in lists are "SURNAME First Middle"; the footer's name is "RATE SURNAME First" as the app writes a rating's name.
- Empty details read "N/A" in facts and "-" in tables.
- The rating report shows the Drafting tab as its sample; the other tabs (Advancement, Training, Education) use the same template with their own columns.
- Handlebars is not a project dependency yet: `render.js` needs `npm i --no-save handlebars` (I installed it that way, so `package.json` has only the script line). WP13 adds it pinned.

## For the next packages (WP13 and those that add a printout)
- Move the templates, partials, `printout.css`, `helpers.js` and `fonts/`, `assets/` to `src/templates/printouts/`; serve them from the app's own files; render with `preferCSSPageSize`, `printBackground`, `displayHeaderFooter` with the footer partial as the footer template (it embeds Inter as a data URI) and an empty header template. Keep `@page` margins from the CSS (12 mm, 17 mm foot).
- Pages load the CSS, crest and fonts by relative URL (`render.js` adds a `<base>`); in the app write the HTML to a temporary file or serve the folder.
- Each template's orientation is set in its `{{> head orientation="..."}}`; `static-table-list` reads `orientation` from its data (landscape over four columns).
- Rows: `group` makes a group heading, `struck` a struck line, `totals` a totals row; column kinds are listed in `helpers.js` and the README.
- A new package's printout is a new `<name>.hbs` plus a sample, using the same partials.
- Names and dates must reach the template ready as the app writes them (dates may be ISO: the `date` helper and column kind `date` format them).
